
# ENDLESS RUNNER 3D

## 1. Giới thiệu
Game chạy vượt chướng ngại vật 3D được xây dựng
bằng Unity 6.3 và ngôn ngữ lập trình C#.

## 2. Công nghệ sử dụng
- Unity 6.3
- C#
- Visual Studio
- Git và GitHub

## 3. Chức năng chính
- Nhân vật tự động chạy.
- Di chuyển trái, phải trên 3 làn.
- Nhảy vượt chướng ngại vật.
- Sinh chướng ngại vật tự động.
- Thu thập đồng xu và tính điểm.
- Tăng tốc độ theo thời gian.
- Màn hình Main Menu và Game Over.
- Lưu điểm cao nhất.
- Hệ thống âm thanh.

## 4. Điều khiển
- A / Left Arrow: Sang trái.
- D / Right Arrow: Sang phải.
- Space: Nhảy.

## 5. Cách mở dự án
1. Tải hoặc Clone repository.
2. Mở Unity Hub.
3. Chọn Add Project from Disk.
4. Chọn thư mục EndlessRunner3D.
5. Mở bằng Unity 6.3.
